# v2 验收规程：以商业发现而非文档数量验收

## 验收对象不是“写了多少字”

每个阶段同时检查 **真实世界证据 → 商业解释 → 可进入性 → 判断价值**。结构化记录、脚本检查、哈希、PR合并仅说明资料可追溯，**永远不能单独用于宣布市场研究完成**。

## 四个关口

**G1 真实对象**：原始卖方/买方页面或可验证的具体交易线索；给出日期、链接、SKU与金额/指标原始口径，并说明哪个是推断。至少包括一项可排除“只有自己幻想”的外部行为信号。只有故事/报告不通过。

**G2 交易机制**：逐项交代谁付款、为什么、现有替代、价格/服务范围、获客、履约、成本与售后；看不到就标最重要的断点。给出至少一项同规格替代/竞争对照，区别真机会与伪价差。

**G3 新人可进入性**：明确第一个客户可能从哪个具体页面/分类出现，上游如何找到，如何提供别人不能轻易绕过的价值，启动资源与失败代价。只写“可以做渠道/对接工厂/用AI提高效率”不通过。

**G4 可放大与行动判断**：明确先测试什么、成功/失败信号、单笔与重复经营的边界、有没有沉淀客户/渠道/品牌/复购或收益权的可能。不能证明长期权利时，明确是短期现金流机会，不为了“创业感”乱称复利。

## 交付阶段

- **阶段0：入口地图和约束**。至少展示不同交易机制而非不同网站名；平台可进入性、样本偏差和需要用户登录配合的阻塞。此时不能宣布全项目完成。
- **阶段1：首轮现场发现**。约6–8个真实异常案例，至少3种机制、覆盖成功/普通或失败对照；每案至少有第一手或直接访问的公开页面证据和下一跳核查。请用户审核研究方向，未审核不得用海量复制扩样替代。
- **阶段2：重点深拆**。至少3个优选或强反例案例做到G1–G3，有可解释的收益结构或不能计算的具体原因，明确另两个替代机会的比较；给出当前先核什么、为何。
- **阶段3：决策与试验提案**。候选按“值得继续深入/值得小测/机制启发/当前暂缓”分层；有具体页面入口、验证所需资源、是否须联系/交易授权；与B匹配时提出客户×产品×人设组合。不要求硬凑三个赢家。

阶段数用于防止过早结案，不表示凑足几个案例就通过。**若某阶段核心关口不能完成，只能记为执行中/待用户输入/受阻，不得用“暂无赢家”冒充已完成深入研究。**

## 反向审查：每个被推为机会的对象至少要回答

1. 买方确实存在，还是只有卖家挂牌/网友泛泛讨论？
2. 所称利润差是否来自同规格、同时点和完整成本？
3. 买家是否可直接从我们选中的供给方获得同等服务？
4. 没有现成客户/人脉的人，第一单究竟在哪个入口出现？
5. 是否需要无法合理获取的资质、资金、地理位置、设备或专业责任？
6. 即使第一单赚到钱，第二十单为何不会仍完全依赖本人劳动？
7. 什么观察能推翻目前的最佳商业解释？研究者是否主动追了它？

允许各项“不知道”，但必须说明下一项区分性核查和优先级。不能因为缺绝对核账把所有机会一票否决，也不能因为“可能高利润”跳过真实买家。

## 研究结束的两种合法状态

- **完成**：用户能够根据上述证据决定先验证哪个机会，以及具体从哪里开始、投入什么、可能失败于什么。
- **阶段受阻/无合格候选**：出示实际覆盖的入口、深拆对象、否证链、尚不可访问的交易证据、用户下一步可授权的最低成本动作。此时完成的是某阶段，不是“市场已经研究完”。

一旦研究明显偏向同类微任务、成熟专家或公开材料摘抄，自动触发暂停和重选样本；不得等待用户再次指出。
