# 既有证据迁移与校核

本次迁移把暂停前“首批10条”整理成可交接的最少公开摘要。迁移没有恢复调研，没有重新访问平台；原始文件只在本机保留。

## 纳入与排除

|源类型|本次用途|公开方式|
|---|---|---|
|XY01、SM01、XHS-001、GUM01保存的页面文字JSON|对照价格单位、公开指标、卖家交付声明及评论主题|自写最少摘要、干净商品链接；不复制全文|
|供给侧6条旧结构化观察JSON|保留起订量、样品费、规格差异等既有线索|明确为旧记录并标`awaiting_review`；不升级为原页面校验|
|旧阶段一摘要、访问记录、暂停记录|确认首批10条组成、平台到达层级与未完成范围|概述访问层级和限制；不是新实测|
|抽样元数据|保留可追踪的关键词、默认排序与位置|未知用`null`，不补造采样路径|

不迁移整页截图、完整页面文字、评论全文、卖家/评论者身份、头像、联系方式、登录状态材料、凭据、带访问令牌URL或本机路径。未将旧记录其余页面凑入首批10条。尤其SM05–SM07只有截图等有限材料，正文已丢失，本次不补录。

## 校核覆盖

- **XY01：** 保存文字支持2元小刀价、10元直接买、另行报价、78想要、427浏览、店铺40件、2–3天及修改口径冲突。未核实际成交与交付。
- **SM01：** 保存文字支持20/50/100元每页、2/3/5天、不限修改、样稿/退款声明及不同评价口径；抽样位置来自旧结构化记录。未核登录状态、成交、转包许可和卖家宣传。
- **XHS-001：** 保存文字支持主帖已找到、互动计数、匿名化评论预算/时限与供给回应。旧访问记录明确使用已有登录状态读取公开评论。未复制身份和评论全文；未核评论有效性、成交及私人转化。
- **GUM01：** 保存文字支持SGD展示价、1252 sales、69 ratings/4.9分、模板复制/教程/更新承诺。未核登录状态、历史价格、实际收入、授权与国内需求。
- **YW01–YW03、MIC01–MIC03：** 只能对照旧结构化观察JSON；未发现独立保存的整页文字，本次也未核读截图像素。保留原观察时间、页面更新时间声明、报价线索、询盘与非线上交易声明及具体缺口，统一待复核。不得描述为6条已完成原文或像素校核。

共10条，4条`checked_against_saved_text`，6条`awaiting_review`。这些状态只说明迁移校核层级；前者也不是真实性认证、重新访问或成交验证。

## 字段规则与证据定位

机器可读记录为 [samples.jsonl](../data/samples.jsonl)，使用`schema_version: 1`。`observed_at`保留旧记录的确切观察时间并统一为`+08:00`；`imported_at`为此次迁移时间，两者不得混用。`observed_date`不是页面上需求、评价或商品更新日期。

`sampling.position`沿用旧记录的排序位置，不是随机样本概率。YW01和MIC01为搜索辅助发现后进入实际详情，无法恢复确切站内排名，相关字段为`null`；同店页和站内搜索页的序号如实保留。

`prices`区分起价、每页价、公开求助预算、件数阶梯和打样费。“面议”没有伪造数字批量单价。`metrics`逐个写明作用域和含义；想要、浏览、评论、目录商品数、店铺累计数均不冒充该SKU当期成交量。

`direct_observations`为自写观察摘要；供给侧待复核记录明确冠以“旧记录载明”。`mechanism_hypotheses`只存需要下一步证据验证的机制猜测。`unverified`、`anomalies.next_check`写明具体缺口，不把线索包装成盈利结论。

证据通过`E-<样本ID>-TEXT`标识。四条页面文字的`kind`为`saved_page_text`；六条旧结构化观察记录的`kind`为`saved_observation_record`，避免把研究者摘要误标成页面原文。所有原始证据`availability`为`local_only`、`public_pointer`为`null`；本机来源映射另行私有保存，未写入公开仓库。

`integrity_sha256`只用于识别迁移时所读文件及检测后续变更，不能证明网页真实、记录完整、销量无刷量或截图来源可靠。六条供给侧共享一个源JSON，因此文件哈希相同；不代表六个独立佐证。

公开仓库只提供摘要与可复访链接，外部读者无法据此独立检验旧截图或原文。下一模型可以依法复访公开页面；若需登录、验证码或访问受阻，记录限制并由用户亲自处理，不继承旧会话，不伪装已进入。

3. 淘宝未进入可读商品详情、1688未通过验证；替代平台不能填补这两个平台的实测缺口。
4. 真实成交价、退款执行、版权许可、运费/税费、获客费、返工工时、供应容量和持续更新均未确认。
5. 暂停前曾多页并行；后续规则已改为一个窗口、一个任务标签、一个浏览执行者。本次未启动浏览或采集。

迁移目标是保留可追踪线索与缺口，第一轮质量仍由后续观察决定；文件数量和结构完整不能替代发现。
