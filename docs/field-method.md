# 第一轮：交易现场观察

平台调研已于2026-10-18获用户恢复。本文件是方法说明，不代表已访问平台或获得样本；当前范围和资源分配以任务源为准。

目标是留下能复核的真实交易画面，并发现下一步值得核查的异常。第一轮主要做筛选和记录；不为凑数量而补低质量页面，也不急着写完整商业模式。

## 1. 每次只解决一个具体问题

例如：“这家店的低价入口究竟交付什么，客户为何还会选更贵的档位？”不要以“研究数字产品市场”作为一次浏览任务。

执行前在会话记录中写明：问题、平台、采样路线、时间预算、文件负责人。由协调者按性能分配独立观察范围；本次最多两个浏览操作者、每人一个任务页面，各自逐页导航。弹出新页时及时收拢。卡顿、额外窗口和资源异常也要记录，必要时停止浏览。

## 2. 选样本：沿交易链走，保留反例

优先从实际能进入的 3–4 个平台开始。先交首批约 10 条有效样本，再决定是否扩展至约 30–50 条；这些是采样预算，不是验收配额。

每条观察单位为“一个具体 SKU/需求 + 规格 + 页面 + 观察时间”。同一店铺的重复链接、同一服务的换标题页面不要当作多个独立商机。可将关联页面放在同一观察记录中。

在平台、交易类型和价格档位之间交叉取样，同时保留：

- 常见基线：同类正常卖法和价格，给异常一个参照。
- 异常样本：价格阶梯、可见需求、履约方式或供需距离值得解释。
- 反例/负样本：同类无人问、公开差评暴露交付问题、规格对不上、成本不成立。
- 失败访问：登录墙、页面失效、空搜索、看不到规格，留在会话记录中。

六种采样方向见 [发现路径](discovery-paths.md)。搜索排序、推荐流、登录状态、地区和平台可访问性都会改变看到的内容；记录入口和排序，不把便利样本推广为全市场结论。

## 3. 逐条打开，记录买家实际购买的东西

从商品/服务/需求详情进入店铺 SKU、公开评价和评论，再沿同类竞争或上游供给走。至少回答下面几个问题；看不到的直接填“不可见”，不要猜：

| 观察对象 | 要留下的信息 |
| --- | --- |
| 商品或需求 | 干净链接、标题、平台、访问时间及状态、用途、规格与计价单位 |
| 价格 | 页面标价、起价/定金/单价的含义、各档位内容、附加费、最小购买量、报价有效条件 |
| 交易信号 | 页面指标原名、原值、统计对象和时间范围；不能确认时写明 |
| 店铺与交付 | 同店价格梯度、可见更新时间、交付物、工期、修改次数、验收/售后承诺 |
| 公开评论 | 自写概括客户在问什么、反复出现的犹豫、缺货、加急、返工、规格误会和差评原因 |
| 入口与流量 | 实际从搜索/分类/店铺/相关推荐/公开笔记等哪里进入；引流去向仅记公开可见事实 |
| 上游及对照 | 对应页面、相同规格是否成立、报价单位、起订量、代发条件、供给时点 |

“想要”“收藏”“咨询”“评论”分别是互动信号；评价数可能混合多个规格或历史款；店铺累计卖出数不是当前 SKU 的成交量。标价和交付承诺也分别不等于实际成交价和履约结果。

## 4. 小细节比“高利润”标签更有用

优先保留能改变判断的细节：低价档排除哪些工作、加急费与返工次数、客户是否自带素材、是否只卖教程/咨询入口、同一评论里的规格误解、看似同款实际尺寸/授权/材料差异、代发是否另收打包费、需求是否已过期。页面粗糙只说明表达方式，不能证明新手容易复制。

每条记录严格分三栏：

- **直接观察**：自己实际看到的页面事实，带观察时间和证据位置。
- **机制推断**：由哪些事实推得、还有什么替代解释。
- **尚未核实**：真实成交、总成本、供货稳定性、权利资质、买家是否愿意付费等缺口。

异常只写一句机制假设，并给一个能推翻它的具体证据。例如“可能赚加急服务费；若高价档包含完全不同的制作工作，这个解释就不成立”。

## 5. 供需相互核对，不先宣布差价

找到公开需求与供应页面后，逐项匹配用途、规格、数量、交付物、授权、时限、修改和售后。明确需求发布时间/是否仍有效，以及供应页面的可见承诺。只有规格相符才比较价格；否则记录差异和最小核查项。

第一轮可做粗略费用核对，不做未经核实的利润预测：

> 单笔剩余 = 可实现收入 − 供给费 − 平台及支付费 − 物流/包装/税费 − 获客费 − 沟通与验收工时成本 − 修改/退款损失

缺失项留空或标“未知”。若要比较情景，分别列低/中/高费用及假设来源；不要把售后风险记成零，也不要把代发报价当作完整履约成本。没有成交价和成本证据时只称“表面价差”。

## 6. 首轮交付与后续入口

先交实际进入与未进入的平台、首批样本链接及脱敏证据摘要、最意外的一个发现、反例和证据缺口。没有异常也应如实说；文档齐全不算市场发现。

扩样后只对有证据支持的异常做必要同类对照，再决定深入核查哪些；原定约10条对照、3–5条深拆不再作为配额。第一轮每条只需留下：值得继续的理由、反证、下一项最小核查；不作机械分数排名。后续验证才回答“谁买、从哪里来、付什么钱、谁交付、剩余在哪、新人如何进入、为何不被绕过、48–72 小时如何试”。发消息、询价、购买、发布和交易测试均需另行授权。

## 7. 留证与复访

使用 [观察模板](../templates/observation.md) 和 [会话模板](../templates/session.md)。链接去掉登录令牌、跟踪参数和私人标识；不能生成干净可访问链接的证据留在本地私有材料中并说明限制。

原始截图和页面材料只保存在各机未跟踪的私有目录，公开仓库只放必要的自写摘要与干净链接；不提交整页截图、完整评论、账号/头像、联系方式或私人聊天。个人身份与买卖问题无关时不记录。登录由用户本人完成；遇到验证码、反爬或权限限制停止该路径，标明未实测，等待正常登录或用户提供材料，不绕过限制。

记录观察时间与页面显示的更新时间，两者不要混用。价格、规格、库存、交期和公开需求有效性可能变化；明确哪些结论须在决策前复访。复访追加新时间和差异，不覆盖旧观察。
