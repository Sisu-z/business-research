# 现场商业侦察 SOP v2

核心方法：**用已有研究缩小值得查的问题 → 进真实交易页面找反常细节 → 追买方与供给 → 复原钱的路径 → 判断新人如何参与 → 寻找反证。** 2026-10-19用户明确允许公开报告优先；报告可节约发现成本，但报告、媒体或抽象分类本身不算现场交易案例。

## 1. 每轮先定覆盖，不预设赢家

记录所进平台、登录情况、实际搜词、排序及访问失败。优先覆盖不同消费人群与交易机制，不把“换了5个平台看同一种低价文件服务”叫广泛调研。

三条相互独立的发现路线：
- **从买家出发**：评论、求购、差评、加急需求、预算询问、退换争议、使用失败；追“最后怎样解决/谁收费”。
- **从卖家出发**：有实际销售迹象的商品 → 同店价格和套餐阶梯 → 主要引流页面和评价 → 同类竞争者。
- **从供给出发**：厂商/1688/服务履约商可交付什么、起订/授权/交期/代理政策 → 找谁在前端以另一种方式打包卖出。

主看中国真实交易与弱公开信息。海外独立站只作为额外灵感和可核对的供需，不得因为容易读就替代中国平台。

## 2. 一条有效“交易观察”至少保留

对象的干净链接、观察日期、平台/搜索入口、商品规格与计价单位、具体客户用途、页面标示的销量/评价/问答 **原标签和归属**、一个有信息增益的异常、一个可反驳的机制解释，以及需补的关键证据。

截图/网页原始证据按既有隐私规则只保存在用户认可的非公开位置；公开仓库保留经过核对的事实摘要和链接。无法浏览封闭页面只写未访问，不能从搜索摘要装成亲访。

**只有“上架中”不等于交易；只有“想要/评论”不等于成交；只有“客户预算”不等于付款。** 可观察到的平台销量与成交自述也不是核账。证据不是非黑即白，保留强弱，不必每条都等拿到银行流水。

## 3. 发现异常以后必须追完整链条

为高潜力异常至少找：
- 前端：原商品/账号的套餐、真实选项、至少一名同范围竞争者及可见购买信号。
- 买方：独立需求或真实买后反馈；优先弄清购买前替代、购买理由、不满意处。没有就标断点，不捏造“客户画像”。
- 上游：同规格、同质量、同服务责任的真实供给；代发、起订、运费、打样、交付/退款均影响实际价差。
- 获客与成交：搜索/推荐/关联SKU/内容/私域引导的真实公开痕迹；不可见环节单列。
- 人的作用：谁来报价、接客、确认规格、垫资、验货、返工、赔付、收款、复购，交易权利属于谁。

强制问一次：**如果我只是中间人，买家为什么不直接绕过我？** 想不出可验证的理由，不能推荐它作为长期资产。

## 4. 经济性与上限，分别判断

情景账本（未知项不填零）：
客户实际可实现客单价 − 采购/外包/生产 − 获客渠道 − 交易/支付/税费 − 物流/坏单/退款 − 沟通及质检管理 − 后续售后责任 = 可估算剩余。

再问这个剩余怎么扩大：可重复同一履约单元？能用其他人/供应商替代本人时间？复购/订阅/批量采购是否存在？能沉淀客户入口或产品资产？竞争者复制要付出什么代价？

**没有直接成交和全部成本，只能给区间/敏感性或暂不估算，不能因不确定就把整条路线判为毫无价值。**

## 5. 必须给“普通新人进入路径”

不能写“联系商家”“找老板合作”这种没有入口的废话。至少列：
1. **去哪里**：平台、分类/搜词、公开需求页面或现成可用合作申请路径（带链接）。
2. **第一份可交换价值是什么**：真实样品、客户线索、渠道曝光、选品/对比、方案/售后组织能力等；没有先说明需要补什么。
3. **怎么试一单**：价格/范围/交付、谁承担责任、需要何种许可与最低现金、怎样判断对方真的会付钱。
4. **如果成功怎样复制**：第二单来自哪里、谁交付、是否有权留住客户与复购；如果仅是零工，明确讲。

接触买卖双方、私信、报价、做号、购买样品等均须先问用户授权。只读阶段输出可执行动作提案，不擅自假称验证成功。

## 6. 抽样与深入的节奏

- **侦察检查点**：先覆盖至少三种明显不同的付费机制，交付约6–8个带页面证据和追查链条的异常案例，供用户判断方向；缺平台访问就及时报告，不靠报告补样本。
- **扩大追踪**：按用户反馈，扩为不同来源/经营主体的样本，形成候选组的同规格竞争和上游/买方对照；不要只追服务接单或只追容易公开核价的英语产品。
- **重点逆向案例**：用 [深拆模板](../templates/deal-case-v2.md)做至少3个完整交易假说，加上失败/普通竞争者对照。可以最终全部暂缓，但必须给出每条被淘汰的具体证据。
- 每5个高信息量样本就给用户一次实质性判断，**不必等到整个仓库写完才第一次请用户纠偏**。数量是探索底线/提醒，不是通过字段数拿验收；欠缺完整交易链不得以完成配额结束。

## 7. 特别防止三种跑偏

- **工具偏好**：不能把任何业务拆成“做表格/整理清单/AI输出”然后误认为有人单独买这一环。先确认客户实际购买的完整成果。
- **过度审计**：发现采购单不等于研究工作应全部变成查该平台保证金。花在审计单一500元任务的精力，必须相称于其规模潜力和信息增益。
- **数据松懈**：不能把不同材质、规格、价格期、地区/平台的产品直接算利润差；同店或转引不能作为独立买方证明。

没有新发现不等于任务完成。说明搜过哪些真实入口、为什么被阻断、用户可提供哪种页面或授权继续。
