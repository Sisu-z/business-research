# 商业调研

研究什么值得卖、谁会买、为什么买，以及普通新人通过学习或合作能否进入。商品、完整服务、撮合、租赁、体验、内容与工具均可研究；不按AI擅长生成什么筛行业。

**先读[2026-10-19判断复审](reports/decision-review-2026-10-19.md)。** 当前没有足够依据推荐投入经营的赢家：Excel当前任务已核到保证金/投标门槛，暂缓现金进场；视频只核精确需求；照片只查现成供给留下的缺口，暂缓先购相机短租。它们是研究取舍，不是收益排行榜或接单建议。

## 本轮改变了什么

- 保留具体需求、规格和替代反例；撤回清单/借还表/对账表天然可单独出售的推断。
- 把双语长片招募、中文口播索引与一般视频买后评价分开，避免拼成同一市场闭环。
- 对比完整结果、现有解决、同范围价格边界、首单入口、可学技能和资金/设备/渠道等资源。
- 设计有时间盒、验收与停止条件的能力试做；它不替代精确需求、准入和支付验证。
- 更新个人背景口径：当前技能、预算、可承诺工时与资源缺失不代填；旧快照不作为技术赛道限制。

1. [AGENTS](AGENTS.md)、[项目目标](docs/charter.md)：当前权限与研究方法。
2. [判断复审](reports/decision-review-2026-10-19.md)：旧结论处置、候选比较、来源与验证。
3. [认知案例覆盖](reports/case-coverage-2026-10-19.md)、[跨领域检查点](reports/discovery-map-2026-10-18.md)、[质量审计](reports/quality-audit-2026-10-18.md)：历史线索，不继续继承已修订的推荐含义。

5. [证据规则](docs/evidence-policy.md)、[现场方法](docs/field-method.md)、[发现入口](docs/discovery-paths.md)：关键词、分类、SKU、公开问答/反馈多路发现，零结果不等于市场不存在。
