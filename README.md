# 商业调研

公开项目：[Sisu-z/business-research](https://github.com/Sisu-z/business-research)。

从真实平台页面、商品规格、评论和履约细节中，发现值得继续验证的交易机会。研究对象是一名资本有限、善用 AI 和快速研究、缺成熟渠道与货源的在校大学生；不预设必须做 AI，也不要求先建立个人 IP。

**第一轮先筛选和记录，质量优先。** 目标不是填满表格，而是找出有具体买卖对象、有不寻常细节、能提出下一步核查的问题。30–50 条是原定采样参考量，可以按有效发现调整；没有值得进入的机会也是有效结果。

## 新模型从这里接手

1. 阅读 [AGENTS.md](AGENTS.md) 与 [HANDOFF.md](HANDOFF.md)，核对当前授权、运行与文件所有权。
2. 阅读 [项目目标](docs/charter.md) 和 [唯一任务记录](tasks/README.md)，领取明确范围后再工作。
3. 阅读 [质量审计](reports/quality-audit-2026-10-18.md)，不要继承已撤回的排序。按任务从不同领域形成具体问题及反证，结合用户说法、用途规格、分类、店铺和公开评论换路；初始关键词不代表平台全貌。商业认知资料与Sisuself-skill只提供线索，私有内容不复制。随后阅读 [现场采样方法](docs/field-method.md)、[发现入口](docs/discovery-paths.md)、[数据字段](docs/data-dictionary.md)，核对现有记录，避免重复采集。

这套入口是普通 Markdown 和 JSONL，不依赖某个模型、聊天软件、付费框架或个人技能。支持代码和浏览器的模型可直接执行；只有阅读能力的模型可以整理、质疑和补充核查清单。

## 项目如何工作

|位置|内容|
|---|---|
|`docs/`|目标、方法、发现入口、证据与协作约定|
|`data/`|经过公开检查的事实摘要与证据元数据|
|`reports/`|阶段筛选记录，优先细节与反例，避免长篇战略|
|`tasks/`|唯一任务状态和运行交接记录|
|`templates/`|现场观察、会话记录和跨机交接模板|
|`scripts/check.py`|本地字段、链接与公开文件检查；不访问市场页面|
|`private/`（不跟踪）|本机原始证据、截图和本机路径映射；不得推送|

浏览由协调者按资源和独立范围分配，本次最多两个浏览执行者、每人一个任务页面；出现内存紧张或卡顿就降为串行。多个 AI 仍须分开文件所有权，另一台电脑不自动加入，见 [多模型与多机协作](docs/collaboration.md)。

## 检查与提交

使用 Python 3.9 或更新版本运行 `python3 scripts/check.py`，检查数据、内部链接和明显的公开风险。它不能证明页面、销量或商业判断真实。新采样还必须人工核对证据及指标含义，见 [证据与公开规则](docs/evidence-policy.md)。

公开前只提交已审文件；不要使用包含原始输出的整目录上传。所有第三方页面、商品、评论及图片的权利仍属于各自权利人；公开记录不构成转售授权。
