任务状态只在本目录维护。Issues、聊天、PR可以讨论或交付，但不得另写冲突的任务状态；HANDOFF仅指向当前任务与检查点。

状态可用：待执行、执行中、暂停、待核、完成、取消。完成要写实际验收结果；暂停记录用户指令，恢复必须有明确授权。没有值得进入的候选可以结束某个方向，不能伪造成功。

同一时间由一个协调者分配范围。执行前核对当前基线，登记运行与文件所有权；若发现其他运行占用同一范围，停止冲突动作先协调。记录不提供原子锁或自动唤醒能力。
